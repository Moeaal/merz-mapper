# Photos for the About page

Drop real photos here with these names and the About page shows them in place of the dashed placeholders.
No code change is needed.

| File | Shows |
| --- | --- |

Keep each under about 400 KB (1600 px wide, JPEG quality ~80), so the page loads quickly on a phone.
Only use photos where nobody can be identified, or with their permission.
