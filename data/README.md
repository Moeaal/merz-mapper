# Data (local only)

Rosbags, saved maps, photos and synthetic runs go here on the laptop. Nothing in this folder except this README is
committed (see the root `.gitignore`): large data lives on the SSD and OneDrive.

The rover writes its runs to `~/merz_data/` on the Jetson. To show one on the website, see
[`../web/README.md`](../web/README.md) ("Import a real rover run").
